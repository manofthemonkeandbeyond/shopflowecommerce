# E-Commerce Order Fulfilment & Inventory Optimization System

## Project title
E-Commerce Order Fulfilment & Inventory Optimization System

## Technologies
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- XAMPP/phpMyAdmin or MySQL server

## How to run
1. Install Node.js.
2. Start MySQL using XAMPP.
3. Open phpMyAdmin and import `database.sql`.
4. Open a terminal in this project folder.
5. Run `npm install`.
6. Run `npm start`.
7. Open `http://localhost:3000`.

## Default database settings
Host: localhost
User: root
Password: empty
Database: ecommerce_db

## Main functions
- View products
- Add products
- Update products
- Delete products
- Add products to cart
- Place customer orders
- Automatically reduce stock after an order
- View orders
- Low-stock highlighting
